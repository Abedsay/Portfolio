## Local Development

Clone the repository:

```bash
git clone https://github.com/Abedsay/Portfolio.git
cd Portfolio
```

Install dependencies:

```bash
npm ci
```

Start the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```

Run linting:

```bash
npm run lint
```

Preview the production build locally:

```bash
npm run preview
```
